## Featured Projects

### [Tennis Network Analysis](https://github.com/giulicastelli/tennis-network-analysis) — Bachelor's thesis
Graph-database analysis of 25 years of ATP and WTA matches with Neo4j and Graph Data Science: dominance concentration, PageRank and rivalry reciprocity.

### [Madrid Air Quality Analysis](https://github.com/giulicastelli/madrid-air-quality-analysis)
Analysis of 64M+ air-quality records: imputation, spatial and correlation networks, parallel computing and NO₂ forecasting in Python.

### [Oral-B Campaign Analytics](https://github.com/giulicastelli/oral-b-campaign-analytics)
P&G business case: Random Forest store targeting in KNIME to maximise campaign ROI, with geospatial enrichment and a Power BI dashboard.

### [Guild Membership Prediction](https://github.com/giulicastelli/guild-membership-prediction)
Machine-learning pipeline on an imbalanced 250K-row dataset, comparing Logistic Regression, Random Forest and CART.

### [ATP Tennis Database](https://github.com/giulicastelli/atp-tennis-database)
Relational database design in MySQL with an ER model, a Python ETL pipeline and analytical SQL queries.

### [FooDataFrame](https://github.com/giulicastelli/foodataframe)
A lightweight pandas-like DataFrame library written in pure Python (OOP, iterators, generators, decorators).
